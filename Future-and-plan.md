# Future and Plan

## Current direction

- Keep the editor guided and calm instead of overwhelming users with too much at once.
- Preserve free-form editing, but add more smart suggestions where standard CV language is common.
- Make the Cambridge template feel like the default polished experience.

## Near-term ideas

- Add smarter suggestion packs per role type, such as engineering, design, product, marketing, and academic CVs.
- Add optional AI-assisted rewriting for summaries and bullet points while keeping manual editing primary.
- Support better empty-state guidance for blank resumes, including examples that can be inserted section by section.
- Add a compact "review warnings" panel for common CV issues such as missing dates, empty links, or blank section titles.

## UX improvements to consider

- Let users collapse completed steps and auto-advance when a section gets its first meaningful content.
- Add lightweight drag-and-drop inside repeated lists like experience roles or projects.
- Add a cleaner "duplicate item" action for entries like jobs, projects, and certifications.
- Add optional section-specific templates, such as different skill layouts or alternate reference styles.
- Add mobile-specific preview gestures so the drawer feels more native on small screens.

## Logic and product improvements

- Filter exports more intelligently so empty or near-empty entries never make it into PDF or DOCX output.
- Add validation helpers for link formats, email shape, and date consistency.
- Add import migration notes when loading very old JSON files so users know what changed.
- Add local version history so users can restore an earlier draft after major edits.

## Future versions

- Version 0.2:
  Improve suggestions, validation, and empty-state onboarding.
- Version 0.3:
  Add role-aware content helpers and better section ordering tools.
- Version 0.4:
  Add multi-variant template tuning, stronger export fidelity, and more contributor tooling.
